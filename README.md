# 📇 5th Python Project: Contact Book

A simple and interactive Command Line Application (CLI) designed to store, search, update, and manage contact information efficiently.

---

## 🌟 Features
- ➕ **Add Contact**: Save new entries with name, phone number, email, and address.
- 👁️ **View Contacts**: Display a formatted list of all saved contact entries.
- 🔍 **Search Contact**: Quickly look up contacts by name or phone number.
- ✏️ **Edit & Delete**: Update details or remove outdated contacts effortlessly.
- 💾 **Data Persistence**: Keep contact entries saved across sessions.
